# Código de conducta

## Nuestro compromiso

En **MGF Workspace** nos comprometemos a ofrecer un entorno abierto, respetuoso y libre de acoso para todas las personas que participen en el proyecto: colaboradores, usuarios y mantenedores.

## Comportamiento esperado

- Usar lenguaje inclusivo y respetuoso
- Aceptar críticas constructivas con profesionalismo
- Centrarse en lo que es mejor para la comunidad y el proyecto
- Mostrar empatía hacia otros miembros de la comunidad

## Comportamiento inaceptable

- Lenguaje o imágenes sexualizadas, o atención sexual no deseada
- Comentarios insultantes o despectivos (trolling)
- Acoso público o privado
- Publicar información privada de terceros sin permiso
- Cualquier conducta que pueda considerarse inapropiada en un entorno profesional

## Responsabilidades del mantenedor

Los mantenedores del proyecto pueden editar, eliminar o rechazar comentarios, commits, issues y pull requests que no cumplan este código de conducta, y pueden excluir temporal o permanentemente a quienes behave de forma inadecuada.

## Alcance

Este código aplica dentro del repositorio, issues, pull requests y cualquier espacio donde se represente oficialmente al proyecto.

## Reportar incidentes

Puedes reportar conductas inaceptables a **brayanalmengorz@gmail.com**.  
Todas las quejas serán revisadas e investigadas de forma confidencial.

## Atribución

Este código de conducta está adaptado del [Contributor Covenant](https://www.contributor-covenant.org), versión 2.1.
