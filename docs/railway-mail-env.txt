# Correo en Railway — MGF Workspace

# Railway BLOQUEA SMTP saliente (Gmail 465/587 → Connection timed out).
# Tu portfolio en Netlify SÍ puede usar Gmail/Nodemailer; Railway NO.
#
# Solución en Railway: Resend (API HTTPS, 3.000 correos/mes gratis).
# Local: sigue usando Gmail SMTP como siempre.
#
# Guía Railway: https://railway.com/deploy/send-emails-on-railway-without-smtp-resend-api-starter--resend-email-railway

# =============================================================================
# RAILWAY (producción) — Resend
# =============================================================================
#
# 1. https://resend.com → cuenta gratis (sin tarjeta)
# 2. API Keys → Create API Key → copia la clave (empieza con re_)
# 3. Para PRUEBAS sin dominio:
#      MAIL_FROM_ADDRESS=onboarding@resend.dev
#      Solo puedes enviar a TU correo de cuenta Resend
# 4. Para PRODUCCIÓN (invitar a cualquier usuario):
#      Domains → Add domain → añade registros DNS (SPF, DKIM)
#      MAIL_FROM_ADDRESS=noreply@tudominio.com
# 5. En Railway → Variables:

MAIL_MAILER=resend
RESEND_API_KEY=re_tu_clave_aqui
MAIL_FROM_ADDRESS=onboarding@resend.dev
MAIL_FROM_NAME=MGF Workspace
QUEUE_CONNECTION=sync

# Quita o deja sin usar en Railway: MAIL_HOST, MAIL_PASSWORD, MAIL_PORT, MAIL_SCHEME, MAIL_USERNAME
